# tugga-data

Veckans extrapriser för appen En tugga i taget (kallelevin.se/tugga).

`erbjudanden.json` uppdateras automatiskt varje måndag med erbjudanden från ICA Supermarket Kronan, Hemköp Torget och Hemköp Kvarnkullen i Mellerud som passar efter en gastric bypass.

Priserna kommer från butikernas egna sidor och kan ändras. Kontrollera alltid i butiken.
